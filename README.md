# 🚁 Drone Navigation System Using Minimum Spanning Tree

This project simulates the construction of a drone delivery network using **Minimum Spanning Tree (MST)** algorithms: **Kruskal's** and **Prim's**. It visualizes how the optimal delivery path is formed based on user-input coordinates or a file input.

---

## 📦 Features

- Add delivery stations via command line or file input
- Detects and avoids duplicate or invalid station coordinates
- Supports **Kruskal's** and **Prim's** MST algorithms
- Calculates and displays the **total minimum delivery distance**
- **Step-by-step animated visualization** of MST construction using `matplotlib`

---

## 🛠 Requirements

- Python 3.7+
- Required libraries:
  - `matplotlib`
  - `numpy`

Install dependencies with:

```bash
pip install matplotlib numpy
```
